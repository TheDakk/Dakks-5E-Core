# Changelog

## 1.0.0 (2026-09-07)

First release. The D&D 5e system's 2014 SRD compendia (Monsters, Spells, Items; SRD 5.1, built from dnd5e 5.2.5 so that any 5.2.5 or later system loads it) rebuilt document for document with Dakk's Ultimate Tokens as every portrait, token and icon: 321 of 331 monsters, 188 of 319 spells and 53 of 872 items carry Dakk's art; the rest keep the system's own. Stats are untouched. Requires the D&D 5e system 5.2.5 or later (verified on 5.3.3) and the Dakk's Ultimate Tokens module 2.0.0 or later, which Foundry offers to install alongside; if the module unchecks itself when enabled, one of those two is below its minimum. The 2024 rules will be a separate module. Compendium: the three packs (Creatures, Spells, Items) sit under "Dakk's Ultimate Tokens" > "D&D 5e (2014)" in the sidebar, the same tree Dakk's D&D 2e Core uses, and carry banners painted in Dakk's hand, shared with the token module (2.3.3 or later). The module also carries a cover and icon for Foundry's setup and install screens. Version numbering begins at 1.0.0; the same-day 0.1.x builds were pre-release iterations of this release.
