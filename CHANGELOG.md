# Changelog

## 0.1.1 (2026-09-07)

Compendium sidebar: the three packs now sit in "Dakk's Ultimate Tokens" > "D&D 5e (2014)", the same tree the token module and Dakk's D&D 2e Core use, and their labels are simply Monsters (SRD), Spells (SRD) and Items (SRD). No data changes.

## 0.1.0 (2026-09-07)

First release. The D&D 5e system's 2014 SRD compendia (Monsters, Spells, Items; SRD 5.1, built from dnd5e 5.2.5 so that any 5.2.5 or later system loads it) rebuilt document for document with Dakk's Ultimate Tokens as every portrait, token and icon: 321 of 331 monsters, 188 of 319 spells and 53 of 872 items carry Dakk's art; the rest keep the system's own. Stats are untouched. Requires the D&D 5e system 5.2.5 or later (verified on 5.3.3) and the Dakk's Ultimate Tokens module 2.0.0 or later, which Foundry offers to install alongside; if the module unchecks itself when enabled, one of those two is below its minimum. The 2024 rules will be a separate module.
